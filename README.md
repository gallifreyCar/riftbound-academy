# 卡牌训练场

这是一个为 GitHub Pages 准备的纯静态教学站点。当前第一门课程是《符文战场 Riftbound》入门教学，包含规则讲解、关键名词、开局步骤、战场区域示意、双方镜像桌面区域、脚本练习对局、时机窗口、战斗步骤和测验，后续可以继续添加其他卡牌游戏。

## 本地预览

直接打开 `index.html` 即可预览，也可以用任意静态服务器托管本目录。

## 发布到 GitHub Pages

1. 新建或打开你的 `username.github.io` 仓库。
2. 把本目录里的 `index.html`、`styles.css`、`app.js` 复制到仓库根目录，或把整个目录作为一个 Pages 项目。
3. 在 GitHub 仓库的 Settings → Pages 中启用 Pages。
